# diff-audit-scratch
Disposable sandbox for a code-review checklist walkthrough

## Usage

- Clone the repository and open the README to follow along with the walkthrough.
- Review the open pull request and step through each item on the code-review checklist.
- Inspect the diff, tags, and line-level review comments to see how the audit flows.
- This repository is disposable — feel free to experiment freely.
